# ROBO-CAR
It is an Arduino-based robotic car,capable of autonomous line following, real-time obstacle avoidance, and Bluetooth-based manual control. This project demonstrates the integration of sensors, motor control, and wireless communication to build an intelligent robotic system while strengthening practical skills in embedded systems and robotics.

Features

 Autonomous path navigation
 Bluetooth-based remote control
 Real-time obstacle avoidance
 DC motor control using the L298N motor driver
 IR sensor-based line following
 Dual operating modes: Automatic and Manual
 Arduino programming for embedded system control
 
Hardware Components

Arduino Uno
L298N Motor Driver
HC-05 Bluetooth Module
IR Sensor Modules
Ultrasonic Sensor (for obstacle detection, if used)
DC Geared Motors
Robot Chassis
Battery Pack

Technologies Used

Arduino IDE
Embedded C/C++
Arduino Libraries
Bluetooth Communication
Sensor Interfacing
PWM Motor Speed Control

Through this project, I gained practical experience in:

Robotics and automation

Wireless robot control using Bluetooth
Motor driver interfacing and PWM control
Hardware debugging and system integration
